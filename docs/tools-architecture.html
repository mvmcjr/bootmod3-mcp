bootmod3-mcp · architecture

Tool surface

Fifteen MCP tools over the bootmod3 map editor, grouped by domain. Every read path goes through a cache first; the REST API is only reached on a miss.

Read path

Cache before network

  • A table tree is fetched once per mapId, then served from memory and disk.
  • save_tables is the only cache invalidator — it clears both tiers.
  • Datalog CSVs are immutable, so their cache is never invalidated.

Focal

compare_maps

  • The only tool that reads two maps at once.
  • Matches tables in tiers, so a reissued id still lines up.
  • Resamples onto map A's axes before diffing cells.

Never leaves disk

Highlights

  • Annotations are a local invention, not a bootmod3 feature.
  • Stored beside the cached CSV; no endpoint backs them.
